## 진로와 프로젝트 제안: 아직 미확정

추천 주력은 로봇 SW/시스템 통합, 차별화 축은 시뮬레이션·센서 검증이다. 우주 SW는 천문학 전공을 활용할 별도 지원 축으로 검토한다. 이는 지원 합격 가능성에 대한 평가가 아니라 현재 배경과 확인한 업무의 연결에 대한 판단이다.

1. **주력: ROS 2 로봇 SW + Unity 센서 시뮬레이션.** Unity에서 센서·동적 장애물·정답 궤적을 제공하고 ROS 2에서 위치추정·주행을 수행한다. 좌표계, 시각 동기화, 센서 노이즈, 지연, 통신 장애를 설계하고 위치 오차·주행 성공률·충돌률·처리 시간을 비교한다.
2. **AI 확장: 합성 데이터와 실제 데이터의 인식 성능 비교.** 조명·노이즈·가림 조건에 따른 성능을 측정한다. 합성 데이터 학습이 실제 성능을 개선한다는 결론은 실험 전에는 가설로 둔다. 실물 데이터는 평가 분리와 촬영 동의를 고려한다.
3. **우주 관심 확장: GNSS가 없는 탐사 환경의 위치추정 검증.** 달/화성 테마를 쓸 수 있지만 지형·조명·센서 조건을 정의하고 알고리즘 오차를 평가해야 한다. 실제 우주 환경 재현이나 우주 기업 JD 충족을 주장하지 않는다. 위성 SW를 목표로 하면 별도의 지상체·궤도/자세·시험 요구 조사가 필요하다.

천문학은 좌표변환·광학·수치계산·오차 분석을 실제로 수행한 경험과 함께 설명할 때 연결된다. 사용자가 해당 경험을 보유했다고 아직 가정하지 않는다. Unity도 학습 경험의 범위가 확인되지 않았으므로 완성 제품 개발 경력으로 표현하지 않는다.

- 짧은 시연 영상, 코드, 성능 표, 설계 이유와 문제 해결 기록

## 남은 확인 사항

최종 학위, 졸업 시점, C++·Python·Linux·Unity의 실제 경험, 희망 근무지역, 인턴 가능 여부, 대학원 의향을 확인하면 지원 대상을 좁힐 수 있다. 전공 제한이 있는 공고는 별도 확인이 필요하다. 상세 요건 미확인 후보는 확인된 공고와 같은 확신 수준으로 취급하지 않는다.
