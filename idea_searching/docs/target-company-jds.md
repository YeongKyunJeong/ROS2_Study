# 사용자 배경을 반영한 목표 기업·JD 비교

조사일: 2026-11-09 KST. 국내 근무, 2025년까지 공개된 신입·인턴 공고를 중심으로 조사했다. 현재 모집 여부는 평가하지 않았다. 2026년 공고는 제외 판단의 보조 자료로만 명시했다.

## 선정 기준과 판단 한계

사용자는 천문학 전공, Unity 게임 개발 학습 경험, 두산 로키 캠프 수강 중이며 Python·PyTorch·OpenCV·ROS 2 실습 코드가 있다. 게임 포트폴리오, 독립 구현 범위, C++ 숙련도는 미확인이다. 현재 자료에 근거한 주력 방향은 로봇 응용 SW·통합, 비전 응용, Unity 기반 시뮬레이션이다.

추천은 기술·직무 적합도와 신입 진입 경로를 기준으로 한다. 보상·재무·근무문화까지 평가한 우량기업 순위나 합격 가능성 순위는 아니다. 특정 전공 필수 공고와 상세 자격 미확인 기업은 조건부 후보로 둔다. 대학원 진학 의향이 확인되지 않아 석사 필수 연구직을 주력으로 추천하지 않는다.

## 준비 우선순위

**C++ 미학습 확인 후 정정:** 사용자는 2026년 말~2027년 초 지원을 준비하며 C++를 배운 적이 없다고 밝혔다. 아래 순위는 직무 연결성 기준이며 즉시 지원 준비 순위로 사용하지 않는다. 단기에는 Python 중심 ROS 응용·비전과 기존 C# 기반 직무를 먼저 선별한다. 네이버랩스 임베디드는 중장기 후보로 내리고, 클로봇·수퍼게이트의 C++ 필요 범위와 전공 조건을 확인한다. 상세 판단은 [학습 배경 문서](learning-profile.md)의 C++ 항목을 따른다.

## 공통 준비 방향

주력 직무는 ROS 2 임무·상태 관리와 비전 입력을 연결하는 응용 SW로 잡고, Unity 자료를 확인하면 시뮬레이션 지원 축을 추가한다. C++는 별도 보완한다. 실험 결과·오류 복구·개인 기여·재현 환경을 설명하는 완결된 프로젝트가 필요하다. 게임 학습은 실무 경력연수로 쓰지 않으며 천문학 전공도 실제 수행한 내용만 강점으로 연결한다.
