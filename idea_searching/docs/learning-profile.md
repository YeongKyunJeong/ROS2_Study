# 학습 배경과 직무 준비 판단

기록일: 2026-11-09 KST. 현재 확인한 자료에 따른 잠정 판단이며 프로젝트의 독자 작성 여부와 실제 숙련도를 확정하지 않는다.

## 사용자 확인 사항

- 천문학과 출신이며 컴퓨터공학 전공자가 아니다.
- 두산 로키 캠프에서 학습 중이다.
- Unity 게임 개발 학습 경험이 있고 관련 자기소개서·포트폴리오는 추후 제공 예정이다. 현재 미검토다.
- 전공 제한과 현재 준비 가능한 수준을 고려해 목표 기업·직무를 선정하기를 원한다.
- C++는 배운 적이 없다. 필요하면 시작할 의향이 있으나, 2026년 말~2027년 초 지원 준비에서 현실적인 투자 범위를 우선 고려한다.

## 확인 자료와 범위

- [PythonStudy](https://github.com/YeongKyunJeong/PythonStudy): 파일 트리와 Dijkstra·경로 복원, 미로 탐색 대표 코드를 읽었다. 기초 문법·클래스·예외·파일 처리·자료구조·그래프 탐색·NumPy/Pandas·OpenCV 등 학습 코드가 있다. 전체 파일 실행이나 코딩 테스트 수준 검증은 하지 않았다.
- [AI_Computer_Vision](https://github.com/YeongKyunJeong/AI_Computer_Vision): 트리, 전이학습 비교·불균형 데이터 처리 코드, project_basecode_v2 노트북의 주요 셀을 읽었다. PyTorch 학습·평가, 전이학습, 데이터 증강, 데이터 분리 등을 다루고 있다. 노트북의 수업 기본 코드와 본인 변경분은 구분되지 않았다.
- [ROS2_Study](https://github.com/YeongKyunJeong/ROS2_Study): README·트리, 순찰 액션 서버와 차선 추종 코드를 읽었다. 서비스·액션·TF·QoS 등의 예제와 OpenCV 영상→조향 명령 처리 코드가 있다. 실물/시뮬레이터 실행 성공이나 본인 기여는 미검증이다. install 폴더의 생성 C++ 코드는 C++ 구현 경험의 근거로 계산하지 않았다.
- [ROKEY_AI Drive](https://drive.google.com/drive/folders/1OUcqxY3FmKNE6E_YCSdhMhiUybkctSt0?usp=sharing): 공유 폴더 접근 가능. 개론·실습·응용 폴더와 실습 내 딥러닝 입문, PyTorch, 평가·검증, MNIST, 하이퍼파라미터, WandB, 전이학습·훈련관리 자료 목록 확인. Drive 파일 본문 전체는 읽지 않았다. 강의 자료의 존재를 수강 완료나 숙련의 근거로 사용하지 않는다.

## 현재 판단

Python·AI·ROS 2 응용 프로젝트를 시작할 학습 기반이 있는 것으로 보인다. 독립적으로 설계·디버깅·검증할 수 있는지는 자료만으로 확정할 수 없다. 순수 SLAM 연구, 고급 임베디드·C++ 시스템 개발을 즉시 주력으로 삼을 근거는 아직 부족하다. 로봇 응용 SW·시스템 통합, 비전 응용·검증, 추후 Unity 포트폴리오를 확인한 뒤 시뮬레이션 SW를 우선 검토한다.

컴퓨터공학 전공이 아니라는 이유로 전체 SW 직무를 제외하지 않는다. 공고를 전공 무관, 이공계/관련 전공(천문학 인정 여부 확인), 특정 전공 필수로 구분한다. 기존 기업 조사에서 네이버랩스는 전공 무관 공고가 확인됐지만 기술 준비 수준은 별도 판단이며, 레인보우로보틱스와 현대오토에버 머신비전은 전공 적격 여부 확인이 필요하다.

## 보완할 증거

수업 예제를 하나 선택해 본인 변경점·변경 이유·실패와 해결·동일 조건 성능 비교·재현 방법을 기록하는 것이 우선이다. 대표 코드 정적 검토에서 전이학습의 Full Fine-tuning 부분은 모든 파라미터를 학습 가능하게 설정하지만 optimizer에는 fc만 전달한다. 명칭과 실제 실험 조건을 일치시키는 검증 경험이 필요하다는 사례이며, 실행 검증이나 수정은 하지 않았다.

확정되지 않은 사항: Unity 숙련도, 개별 코드의 독자 작성 범위, AI 도구 활용 범위, 실제 실행 결과, 최종 학위·졸업 시점, 인턴 가능 조건.

## C++ 미학습을 반영한 단기 준비 제안

2026-11-09 기준 연말까지 약 7주, 2027년 1~2월까지 약 2~4개월이다. 이 기간에 C++ 기초와 작은 ROS 2 노드를 학습하는 목표는 설정할 수 있으나 C++ 심화·최적화·임베디드 역량을 요구하는 직무의 필수 조건을 충족한다고 예상할 근거는 없다.

단기 지원은 Python 중심 ROS 2 응용·통합, Python 비전 응용, 기존 C# 역량을 확인한 뒤 Unity 시뮬레이션에 집중하는 것을 제안한다. C++ 학습은 지원의 선행 조건으로 두지 않고 가용 준비 시간의 약 10~20%로 병행하는 예시를 제시한다. 이는 사용자와 확정한 일정이나 숙련 보장이 아니다.

네이버랩스 임베디드 직무는 단기 주력에서 제외하고 중장기 후보로 둔다. 클로봇의 과거 C++/Python 표기는 Python만으로 지원 가능하다고 확정할 수 없어 역할·언어 조건 확인이 필요하다. 수퍼게이트도 C/C++가 명시돼 있으므로 C++ 불필요 직무로 분류하지 않는다. 이노시뮬레이션은 신입 상세 조건과 Unity 포트폴리오 확인이 남아 있다.
