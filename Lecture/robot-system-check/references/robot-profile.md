# 로봇별 검사 기준

빈 값은 미정이다. 실제 로봇 정보로 채우거나 이 파일을 복사해 로봇별로 관리한다.
아래 예시는 작성법이며 기본값이나 검사 대상이 아니다.

| 항목 | 설정값 | 작성 예시 |
|---|---|---|
| 로봇 이름 | | 실습 로봇 A |
| 실행 위치 | | 로봇 PC / 실습 PC / 컨테이너 |
| 실제 로봇 또는 시뮬레이터 | | 시뮬레이터 |
| 운영체제 | | Ubuntu 24.04 |
| ROS2 배포판 | | jazzy |
| 워크스페이스 경로 | | /home/user/ros2_ws |
| ROS_DOMAIN_ID | | 10 |
| RMW 구현 | | rmw_fastrtps_cpp |
| 필수 노드(전체 이름) | | /robot/driver, /robot/lidar |
| 필수 토픽 및 메시지 타입 | | /scan: sensor_msgs/msg/LaserScan |

## 센서별 기준

필요한 만큼 행을 추가한다. 정상 수신 기준과 관측 시간을 별도로 정한다.
주파수 검사가 필요 없으면 주파수 범위는 비워 둔다.

| 센서 이름 | 토픽 | 메시지 타입 | 정상 수신 기준 | 관측 시간(초) | 정상 주파수 범위(Hz) | 발행 QoS(알면 작성) |
|---|---|---|---|---|---|---|
| | | | | | | |

작성 예시: 라이다 / `/scan` / `sensor_msgs/msg/LaserScan` / 10초 내 새 메시지 1건 이상 / 10 / 8~12 / best_effort, volatile.
