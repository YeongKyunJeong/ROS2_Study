먼저 용어를 바로잡으면
쿼터니언은 새로운 공간 좌표계가 아니라 3차원 자세·회전을 표현하는 방법입니다. 위치 (x, y, z)는 그대로이며, 자세를 네 성분 (x, y, z, w)으로 나타냅니다. 이름이 같은 x, y, z라도 위치 값과 쿼터니언 성분은 다릅니다.

오일러 각: 회전 세 번으로 표현

롤 φ는 X축, 피치 θ는 Y축, 요 ψ는 Z축 회전입니다. 일상적으로 오일러 각이라 부르지만 서로 다른 세 축을 쓰는 이 조합은 엄밀히 Tait–Bryan 각입니다.

이 자료의 약속

오른손 좌표계, 열벡터, 능동 회전. R = Rz(ψ) Ry(θ) Rx(φ), v′ = Rv를 사용합니다. 고정축 X→Y→Z 회전과, 움직이는 축 Z→Y′→X″ 회전은 이 행렬에서 동등합니다.

UI는 도(°), 수식 미분과 코드는 라디안 기준입니다. 아래 짐벌 그림은 동등한 내재적 Z→Y′→X″ 구조를 보여줍니다. X 앞 / Y 왼쪽 / Z 위인 ROS 관례에서 양의 피치는 앞쪽 X를 아래로 기울입니다.

01 / TOUCH THE SINGULARITY

피치를 90°로 놓아 보세요.

세 링은 회전 관절, 가운데 화살표 모양은 물체입니다. 피치가 90°가 되면 바깥 요축과 안쪽 롤축이 같은 직선 위에 놓입니다. 부호는 반대지만 독립적인 방향은 하나입니다.

● 안쪽 롤 X″● 중간 피치 Y′● 바깥 요 Z

점선: 회전축 · 실선: 링 · 흰 물체: 최종 자세. 물체의 직교 좌표축과 짐벌의 회전축은 서로 다른 개념입니다. 그림은 고정 시점의 직교 투영입니다.

회전 제어

각속도 야코비안 det J = cos θ

A ↔ B: 링의 표시점은 움직이지만 흰 물체의 자세는 같습니다. C: 롤만 바꾸면 물체도 회전합니다. “롤이 아예 작동하지 않는다”는 뜻은 아닙니다.


02 / WHY IT HAPPENS
두 개의 입력이 같은 회전 방향을 담당한다.
STEP 1 · 회전축의 정렬
월드에서 본 요축과 롤축은 다음과 같습니다. 피치축은 aθ = (−sin ψ, cos ψ, 0)입니다.
aψ = (0, 0, 1)
aφ = Rz(ψ) Ry(θ) (1, 0, 0)
   = (cosψ cosθ, sinψ cosθ, −sinθ)

θ = +90° → aφ = (0, 0, −1) = −aψ
θ = −90° → aφ = (0, 0, +1) = +aψ
결국 세 회전 입력이 만드는 순간 회전 방향은 두 개뿐입니다. 물체의 X·Y·Z 직교축 자체가 겹치는 것이 아닙니다.
STEP 2 · 각속도의 계수 행렬
오일러 각 변화율과 물체 기준 각속도 ωB의 관계를 쓰면:
ωB = J [φ̇, θ̇, ψ̇]ᵀ

    ⎡1     0       −sinθ     ⎤
J = ⎢0    cosφ     sinφ cosθ ⎥
    ⎣0   −sinφ     cosφ cosθ ⎦

det J = cosθ
θ = ±90°에서 det J = 0, rank J = 2. 역행렬이 존재하지 않아 임의의 각속도를 유한한 오일러 각 변화율로 나타낼 수 없습니다. [2]


행렬을 직접 대입하면: θ = +90°에서 φ−ψ만 남는다
c와 s를 각각 cos, sin으로 줄여 쓰고 기본 회전행렬을 곱합니다.
Rx(φ) = [1  0   0 ; 0 cφ −sφ ; 0 sφ cφ]
Ry(θ) = [cθ 0  sθ ; 0  1   0 ; −sθ 0 cθ]
Rz(ψ) = [cψ −sψ 0 ; sψ cψ 0 ; 0 0 1]

R = Rz Ry Rx
  ⎡cψ cθ   cψ sθ sφ − sψ cφ   cψ sθ cφ + sψ sφ⎤
  ⎢sψ cθ   sψ sθ sφ + cψ cφ   sψ sθ cφ − cψ sφ⎥
  ⎣ −sθ          cθ sφ              cθ cφ      ⎦

θ = +90°:
R = ⎡ 0    sin(φ−ψ)    cos(φ−ψ) ⎤
    ⎢ 0    cos(φ−ψ)   −sin(φ−ψ) ⎥
    ⎣−1        0           0    ⎦
φ와 ψ에 같은 양 δ를 더해도 φ−ψ는 변하지 않습니다. 따라서 (0°, 90°, 0°) = (30°, 90°, 30°) = (120°, 90°, 120°)는 모두 같은 자세입니다. θ = −90°에서는 φ+ψ에만 의존하므로 두 각에 반대 부호의 δ를 더하면 자세가 같습니다.
특이해지는 것은 오일러 각 ↔ 자세 사이의 매개변수화입니다. 회전행렬 R은 여전히 정상이고 det R = +1입니다. det J = 0과 혼동하지 마세요.


90° 근처에서도 왜 흔들릴까?
φ = 0일 때 ωB = (0, 0, 1°/s)를 만들려면 θ̇ = 0, ψ̇ = 1/cos θ, φ̇ = tan θ (°/s)가 필요합니다. 역변환이 오차에 민감해집니다.

03 / REAL SYSTEMS, CONCRETE NUMBERS
장치의 한계와 표현의 한계를 구별하기
① 3축 카메라 짐벌
위 실험과 같은 Z–Y′–X″ 짐벌에서 (롤, 피치, 요) = (0°, 90°, 0°). 롤 +10°와 요 −10°는 같은 방향의 회전을 만듭니다. 롤 +10°와 요 +10°를 함께 주면 서로 상쇄됩니다.
이 자세에서 사라진 방향의 순간 회전을 만들려면 먼저 다른 자세로 벗어나야 합니다. 쿼터니언 소프트웨어를 넣어도 기계적 축 정렬은 없어지지 않습니다.
교육용 기구 예시입니다. 실제 제품의 축 배치·가동 범위·제어 방식은 다를 수 있습니다.
② 로봇·드론의 자세 표시
실제 회전이 Ry(89°) → Ry(90°) → Ry(91°)로 부드럽게 변해도, 피치를 [−90°, 90°]로 제한하는 대표 RPY 출력은 다음처럼 바뀔 수 있습니다.
(0°, 89°, 0°)
(0°, 90°, 0°)  ← 한 가지 대표값
(180°, 89°, 180°)
마지막 두 180° 점프는 물체가 갑자기 뒤집혔다는 뜻이 아닙니다. 쿼터니언은 (0, sin(θ/2), 0, cos(θ/2))로 연속 변화합니다. 특이점의 롤·요 출력 규칙은 라이브러리마다 다릅니다. [3]
실제 역사 사례: Apollo의 3축 관성 플랫폼
NASA의 Apollo 11 Lunar Surface Journal은 안쪽·바깥쪽 짐벌축이 정렬되는 현상과, 이에 대한 운용상의 주의를 설명합니다. 이것은 단지 화면에 표시되는 오일러 각 문제가 아니라 기계적 관성 플랫폼의 문제였습니다. [4]
위의 90° 예시는 이 자료의 ZYX 약속을 따른 교육용 수치입니다. Apollo 기체의 축 이름과 짐벌각 정의에 그대로 대입해서는 안 됩니다.


04 / ONE AXIS, ONE ROTATION
회전을 네 개의 수에 담는 방법
어떤 3차원 회전도 하나의 축 u 주위로 α만큼 돌리는 회전으로 나타낼 수 있습니다. 단위 쿼터니언은 이 축과 각을 함께 저장합니다.
복소수의 확장
q = w + xi + yj + zk
i² = j² = k² = ijk = −1
ij = k, jk = i, ki = j
ji = −k  (곱의 순서가 중요)

저장 순서: q = (x, y, z, w)
x² + y² + z² + w² = 1
네 성분에 길이 1 제약 하나가 있으므로 자유도는 여전히 3입니다. 단위 쿼터니언은 4차원 공간의 단위 구면 S³ 위에 있습니다.
축–각 → 쿼터니언
‖u‖ = 1
q = (ux sin(α/2), uy sin(α/2),
     uz sin(α/2), cos(α/2))

Z축 +90°:
u = (0, 0, 1), α/2 = 45°
q = (0, 0, 0.707107, 0.707107)
q와 −q는 같은 회전을 나타냅니다. 그래서 360° 회전 후 쿼터니언 부호가 바뀌어도 자세는 같습니다. 반각과 두 겹 표현은 연결되어 있습니다.
벡터를 실제로 회전시키기: 왜 q v q* 인가?
벡터 v를 순허수 쿼터니언 p = (vx, vy, vz, 0)로 둡니다. p′ = q ⊗ p ⊗ q*의 벡터 부분이 회전된 벡터입니다. 단위 q의 역원은 켤레 q* = (−x, −y, −z, w)입니다.
q₁ = (v₁, w₁), q₂ = (v₂, w₂)
q₁ ⊗ q₂ = (w₁v₂ + w₂v₁ + v₁×v₂,
             w₁w₂ − v₁·v₂)

이를 q p q*에 전개하면 Rodrigues 회전식:
v′ = v cosα + (u×v) sinα + u(u·v)(1−cosα)

Z축 90°, v = (1, 0, 0) → v′ = (0, 1, 0)
양쪽 곱의 전개에서 반각의 배각 공식이 실제 회전각 α를 만듭니다. 비단위 q에 켤레만 쓰면 순수 회전이 아니므로 회전용 쿼터니언은 정규화해야 합니다.
왜 짐벌락을 피하는가?
단위 쿼터니언을 상태로 유지하고 회전을 곱으로 갱신하면, 세 오일러 각의 특이한 좌표 변환을 매번 거치지 않습니다. S³에서 SO(3)로의 대응은 국소적으로 특이하지 않습니다. 다만 오일러 각으로 다시 읽어내면 ±90°의 모호함은 돌아옵니다.
표현저장 수장점주의점
오일러 각3사람에게 직관적순서 의존, 특이점, 각도 경계
회전행렬9벡터 변환이 직접적, 짐벌락 없음RᵀR = I, det R = 1 유지
단위 쿼터니언4간결한 합성, 특이점 없는 자세 갱신, 보간정규화, q/−q 부호 관리, 곱 순서
회전행렬도 짐벌락이 없습니다. 쿼터니언만이 유일한 해결책은 아니며, 성능 우위는 연산 종류와 구현에 따라 달라집니다.


05 / CONVERT & VERIFY
실제 자세를 쿼터니언으로 바꾸기
입력이 무엇인지 먼저 확인하세요. 점 하나의 위치만으로 자세는 정해지지 않습니다. RPY, 축–각, 또는 두 프레임 사이의 회전행렬이 필요합니다.
A. RPY → 쿼터니언
q = qz(ψ) ⊗ qy(θ) ⊗ qx(φ)를 전개합니다. 아래 c와 s는 반드시 각도의 절반에 대한 cos, sin입니다.
cr = cos(φ/2), sr = sin(φ/2)
cp = cos(θ/2), sp = sin(θ/2)
cy = cos(ψ/2), sy = sin(ψ/2)

x = sr cp cy − cr sp sy
y = cr sp cy + sr cp sy
z = cr cp sy − sr sp cy
w = cr cp cy + sr sp sy
변환 계산기
각도를 바꾸면 쿼터니언, 회전행렬과 회전된 X 단위벡터가 함께 바뀝니다.
옅은 선: 월드 축 · 색 선: 회전 후 물체 축. 물체의 세 축은 언제나 서로 수직입니다. 축의 2D 투영은 겹쳐 보일 수 있습니다.
예시 (30°, 45°, 60°):
q ≈ (0.022260, 0.439680,
0.360423, 0.822363)


B. 좌표 프레임 → 회전행렬 → 쿼터니언
물체 프레임 B의 세 단위축을 월드 A에서 표현하여 열벡터로 쌓으면 RAB입니다. vA = RABvB. 다음은 B가 A의 Z축을 기준으로 +90° 돌아간 예입니다.
xB = (0, 1, 0), yB = (−1, 0, 0), zB = (0, 0, 1)
RAB = [ xB | yB | zB ] = ⎡0 −1 0⎤
                          ⎢1  0 0⎥
                          ⎣0  0 1⎦
trace(R) = 1
w = √(1 + trace(R))/2 = √2/2
x = (R32 − R23)/(4w) = 0
y = (R13 − R31)/(4w) = 0
z = (R21 − R12)/(4w) = √2/2
이 trace 식은 w ≈ 0인 180° 근처에 적합하지 않습니다. 일반 구현은 가장 큰 대각 성분에 따라 분기하는 알고리즘을 사용합니다. 아래 예제는 라이브러리에 맡깁니다. 입력 R은 RᵀR = I이고 det R = +1인 회전행렬인지 확인하세요. [5]
위치까지 있는 포즈라면 pA = RABpB + tAB입니다. 예를 들어 t = (1, 2, 0), pB = (1, 0, 0)이면 pA = (1, 3, 0). 회전은 q, 이동은 t에 별도로 보관합니다. 반대 프레임 변환에는 Rᵀ와 −Rᵀt를 사용합니다.


바로 재현하는 Python / ROS 2 예제
import numpy as np
from scipy.spatial.transform import Rotation as R

# 소문자 xyz = 고정축 X → Y → Z (이 자료의 RPY)
r = R.from_euler('xyz', [30, 45, 60], degrees=True)
q = r.as_quat()  # (x, y, z, w), 기본 순서
print(np.round(q, 6))
# [0.022260 0.439680 0.360423 0.822363]

R_AB = np.array([[0., -1., 0.],
                 [1.,  0., 0.],
                 [0.,  0., 1.]])
assert np.allclose(R_AB.T @ R_AB, np.eye(3))
assert np.isclose(np.linalg.det(R_AB), 1)
q_AB = R.from_matrix(R_AB).as_quat()
print(q_AB)  # [0, 0, √2/2, √2/2]
print(R.from_quat(q_AB).apply([1, 0, 0]))  # ≈ [0, 1, 0]

# ROS 2 환경에서 메시지로 전달
from geometry_msgs.msg import Quaternion
msg = Quaternion(x=float(q[0]), y=float(q[1]),
                 z=float(q[2]), w=float(q[3]))
필요 환경: Python + NumPy + SciPy. 마지막 메시지 부분은 ROS 2 환경을 source한 뒤 실행합니다. SciPy의 대문자 'ZYX' 내재 회전은 입력 순서가 [yaw, pitch, roll]이며, 소문자 'xyz'와 구별해야 합니다.
// ROS 2 / tf2: 입력 각도는 radian
#include <tf2/LinearMath/Quaternion.h>
#include <tf2_geometry_msgs/tf2_geometry_msgs.hpp>

const double d2r = 3.141592653589793 / 180.0;
tf2::Quaternion q;
q.setRPY(30*d2r, 45*d2r, 60*d2r);
q.normalize();
auto msg = tf2::toMsg(q);  // x, y, z, w
위 C++는 함수 내부에서 쓰는 핵심 코드입니다. ROS 2의 RPY·메시지 관례는 공식 튜토리얼을 따릅니다. [1]


C. 연속 회전의 갱신과 보간
월드 축 기준 회전 Δq를 추가하면 qnew = Δq ⊗ q, 물체 축 기준이면 qnew = q ⊗ Δq입니다. 매번 RPY로 바꾸고 각을 더하면 쿼터니언을 저장하더라도 특이점 문제를 다시 만들 수 있습니다.
보간 실험: 요 +170° → −170°
단순 각도 선형 보간은 340° 돌아가지만, 최단 경로 SLERP는 20° 회전합니다. 이 예시는 ±180° 경계 문제이며, 짐벌락 자체는 아닙니다. [6]
위에서 내려다본 X–Y 평면. X는 오른쪽, Y는 위쪽입니다. t = 0.5에서 왼쪽은 0°, 오른쪽은 180°입니다.
SLERP 공식과 부호 처리
q0·q1 < 0 이면 q1 ← −q1  (같은 자세, 가까운 부호 선택)
Ω = acos(clamp(q0·q1, −1, 1))
q(t) = sin((1−t)Ω)/sinΩ · q0 + sin(tΩ)/sinΩ · q1
Ω가 아주 작을 때는 정규화한 선형 보간을 사용해 0으로 나누는 문제를 피합니다. SLERP는 일정한 각속도로 두 자세 사이의 최단 회전을 따릅니다. 상대 회전이 정확히 180°면 최단 경로의 방향 선택이 유일하지 않습니다. 이 페이지의 실험도 부호 보정과 작은 각 분기를 구현합니다.

25분 스터디 진행안
  1. 3분 · 용어와 약속 — 위치와 자세를 구별하고 R = Rz Ry Rx를 먼저 선언합니다.
  2. 5분 · 실험 — 일반 자세 → 피치 90° → A/B/C. “롤과 요를 같이 30° 바꾸면 왜 물체는 그대로일까요?”
  3. 5분 · 수학 — φ−ψ만 남는 행렬과 det J = cos θ를 연결합니다.
  4. 4분 · 쿼터니언 — 축–각과 반각, 길이 1 제약, q와 −q를 설명합니다.
  5. 5분 · 변환 — Z축 90° → 복합 회전 → 좌표 프레임 예시를 계산기로 확인합니다.
  6. 3분 · 정리와 질문 — 회전행렬도 해결책이라는 점, 기계 짐벌락과 각도 경계를 구별합니다.
Q. 자유도 하나가 사라지면 물체는 2차원으로 움직이나요?
아닙니다. 3D 자세 공간은 그대로입니다. 특이점에서 오일러 각 세 개의 미소 변화가 독립적인 세 회전 방향을 만들지 못한다는 뜻입니다. 기계 짐벌에서는 실제 관절이 만드는 순간 각속도 방향도 제한됩니다.
Q. 쿼터니언 4개가 서로 다른 회전 네 개를 뜻하나요?
아닙니다. 축–각 정보를 반각으로 조합한 네 성분이며 단위 길이 제약을 가집니다. x, y, z, w 각각을 독립적인 회전각처럼 해석하면 안 됩니다.
