02 / GIMBAL LOCK, STEP BY STEP
짐벌락 수식: 90°에서 두 각이 하나로 묶인다.
먼저 최종 자세가 롤과 요의 차이에만 의존한다는 것을 보겠습니다. 그다음 “독립적인 회전 방향이 줄어든다”는 말을 각속도 행렬로 확인합니다.
기호 안내 · φ(파이) = 롤, θ(세타) = 피치, ψ(프사이) = 요.

1 / 회전 순서를 먼저 고정
고정축 X → Y → Z
열벡터에 작용하는 행렬은 오른쪽부터 적용합니다. 따라서 롤 → 피치 → 요의 순서는 다음과 같습니다.
R=Rz(ψ)Ry(θ)Rx(φ)
중간 피치를 +90°로 놓으면 cos θ = 0, sin θ = 1입니다. 이 값을 세 회전행렬의 곱에 대입합니다.
피치 θ = +90°일 때R=[0sin(φ−ψ)cos(φ−ψ)0cos(φ−ψ)−sin(φ−ψ)−100]
남은 각도는 φ − ψ 하나뿐입니다. 롤과 요를 따로 알아낼 수 없습니다.
(φ+δ)−(ψ+δ)=φ−ψ
예를 들어 (φ, θ, ψ) = (0°, 90°, 0°)와 (30°, 90°, 30°)는 둘 다 φ − ψ = 0°이므로 같은 행렬, 같은 자세입니다. 실험의 A와 B가 일치하는 이유입니다.
θ = −90°에서는 φ + ψ에만 의존합니다. 이때는 롤과 요를 반대 방향으로 같은 양만큼 바꾸면 자세가 유지됩니다.

3 / 독립적인 회전 방향을 세는 방법
각속도 야코비안의 계수가 3에서 2로
물체 기준 각속도 ωB와 세 각의 변화율 사이의 관계입니다. J의 각 열은 롤·피치·요 변화율 하나가 만드는 각속도 방향을 뜻합니다.
ωB=J[φ˙θ˙ψ˙]
J=[10−sinθ0cosφsinφcosθ0−sinφcosφcosθ]
역행렬이 존재하는지 확인detJ=cosθ
θ = +90°이면 첫째 열은 (1, 0, 0), 셋째 열은 (−1, 0, 0)입니다. 하나가 다른 하나의 −1배이므로 두 입력이 같은 방향을 담당합니다. 둘째 열은 이 방향과 독립이므로 rank J = 2입니다. −90°에서는 첫째·셋째 열이 같습니다.
θ=±90°⇒detJ=0⇒rankJ=2
즉 이 자세에서는 임의의 3차원 각속도를 유한한 φ̇·θ̇·ψ̇로 만들 수 없습니다. 이는 회전 자체가 사라진다는 뜻이 아니라, 세 각으로 회전을 표현하는 방법의 특이점입니다. [2]
R과 J를 구별하세요. 회전행렬은 여전히 det R = +1입니다. 특이해지는 것은 각 변화율과 각속도를 연결하는 J입니다.

05 / THE PROOF — qvq⁻¹
왜 v′ = qvq⁻¹이 회전인가?
“로드리게스 공식과 같다”에서 멈추지 않고, 그 결과가 정말 축 u 주위의 α 회전인지 끝까지 확인합니다. [7]
① 기호와 조건② 두 번의 곱셈③ 실제 회전임을 증명④ 숫자로 직접 계산


1 / 무엇을 증명할 것인가?
벡터 v를 순허수 쿼터니언 V로 넣는다.
v는 3차원 벡터이고 V = (v, 0)는 그 벡터를 담은 쿼터니언입니다. 흔히 쓰는 v′ = qvq⁻¹은 이 삽입과 벡터 부분 추출을 생략한 표기입니다. 정확한 식은 다음과 같습니다.
V=(v,0),V′=qVq−1=(v′,0)
성분 순서는 끝까지 (벡터 부분, 스칼라 부분), 즉 (x, y, z, w)를 사용합니다. u는 길이가 1인 회전축이며 회전축은 원점을 지납니다. 회전의 양의 방향은 오른손 법칙입니다.
∥u∥=1,c=cosα2,s=sinα2
q=(su,c),q−1=(−su,c)
∥q∥2=s2+c2=1
단위 쿼터니언에서는 역원 q⁻¹이 켤레 q*와 같습니다. 일반적인 0이 아닌 쿼터니언의 역원은 q*/‖q‖²이며, 단위 조건 없이 q*로 대체하면 크기가 달라질 수 있습니다.
목표: qVq⁻¹의 스칼라 부분이 0이고, 벡터 부분이 u축 주위로 α만큼 회전한 v라는 것을 보이기.


2 / 곱셈을 생략 없이 전개
첫 번째 곱 qV, 두 번째 곱 (qV)q⁻¹
사용할 규칙은 Hamilton 곱 하나입니다. a·b는 내적(스칼라), a×b는 외적(벡터)입니다.
쿼터니언 곱셈 규칙(a,a0)(b,b0)=(a0b+b0a+a×b,a0b0−a·b)
① 왼쪽에서 q를 곱합니다. q = (su, c), V = (v, 0)를 그대로 대입합니다.
qV=(cv+s(u×v),−s(u·v))
계산을 간단히 쓰기 위해 벡터 부분을 a, 스칼라 부분을 β(베타)로 부르겠습니다.
a=cv+s(u×v),β=−s(u·v)
② 오른쪽에서 q⁻¹ = (−su, c)를 곱합니다.
(qV)q−1=(−sβu+ca−s(a×u),βc+s(a·u))
스칼라 부분: 반드시 0이 된다.
u×v는 u와 수직이므로 (u×v)·u = 0입니다. 따라서 a·u = c(v·u)입니다.
βc+s(a·u)=−sc(u·v)+sc(v·u)=0
결과가 순허수 쿼터니언이므로, 다시 3차원 벡터로 읽을 수 있습니다.
벡터 부분: 외적 항을 정리한다.
v′=s2(u·v)u+c2v+cs(u×v)−sc(v×u)−s2((u×v)×u)
다음 두 외적 항등식을 사용합니다. 마지막 등식은 ‖u‖ = 1을 사용합니다.
v×u=−(u×v)
(u×v)×u=v(u·u)−u(v·u)=v−(u·v)u
이를 대입하면 c s 항 두 개가 합쳐지고, 축 방향 항도 두 개가 합쳐집니다.
v′=(c2−s2)v+2cs(u×v)+2s2(u·v)u
③ 반각을 원래 각 α로 바꿉니다.
c2−s2=cosα,2cs=sinα,2s2=1−cosα
얻어진 결과: 로드리게스 회전식v′=vcosα+(u×v)sinα+u(u·v)(1−cosα)
이로써 쿼터니언 곱에서 위 벡터 식이 직접 나왔습니다. 이제 이 식이 실제로 α 회전을 뜻하는지 확인할 차례입니다. 반각 α/2를 쓰는 이유도 여기 있습니다. 두 번의 곱셈이 배각 공식을 통해 최종 각 α를 만듭니다.


3 / 식의 모양이 아니라 회전의 의미를 확인
평행 성분은 고정, 수직 평면에서는 2D 회전
v를 축 u에 평행한 성분 v∥과 수직인 성분 v⊥으로 나눕니다.
v∥=(u·v)u,v⊥=v−v∥
u×v∥ = 0이므로 u×v = u×v⊥입니다. 이 분해를 방금 얻은 식에 넣으면:
회전의 구조가 드러나는 형태v′=v∥+v⊥cosα+(u×v⊥)sinα
첫째, 축에 평행한 성분 v∥은 그대로입니다. 따라서 축 방향 위치는 변하지 않습니다.
둘째, 수직 성분은 같은 평면에서 α만큼 회전합니다. v⊥ ≠ 0일 때 r = ‖v⊥‖로 두고, 그 평면의 두 단위벡터를 만듭니다.
r=∥v⊥∥,e1=v⊥r,e2=u×e1
u와 e₁이 수직인 단위벡터이므로 e₂도 단위벡터이고, e₁과 e₂는 서로 수직입니다. 또한 e₁×e₂ = u이므로 e₁에서 e₂로의 방향은 u에 대한 양의 회전 방향입니다.
v′=v∥+r(cosαe1+sinαe2)
이 평면에서 원래 수직 성분의 좌표는 (r, 0), 결과의 좌표는 (r cos α, r sin α)입니다. 이는 바로 반지름 r인 원 위에서 α만큼 이동한 좌표입니다.



증명 완료. 축 방향 성분은 유지되고, 수직 성분은 길이를 유지하면서 오른손 방향으로 α만큼 회전합니다. 따라서 qVq⁻¹의 벡터 부분은 정확히 u축 기준 α 회전 결과입니다.
∥v′∥2=∥v∥∥2+r2(cos2α+sin2α)=∥v∥2
v가 u와 평행하면 r = 0이어서 v′ = v입니다. 영벡터도 그대로입니다. 일반적으로 v와 v′ 자체가 이루는 3차원 각이 α인 것은 아닙니다. α는 u에 수직인 평면에서의 회전각이며, v가 u에 수직일 때 두 개념이 일치합니다(각도의 주기와 주값 범위에 유의).


4 / 숫자로 두 번 곱해보기
Z축 90°: X 방향 벡터가 Y 방향으로
u = (0, 0, 1), α = 90°, v = (1, 0, 0)으로 놓습니다. 순허수 단위 i, j, k를 쓰면 V = i이고, 계산에 필요한 규칙은 ki = j, ik = −j, jk = i입니다.
h=22,q=h+hk,q−1=h−hk
첫 번째 곱qV=(h+hk)i=hi+hj
(qV)q−1=(hi+hj)(h−hk)
=h2i−h2ik+h2j−h2jk
두 번째 곱: i 성분은 상쇄, j 성분만 남음=h2i+h2j+h2j−h2i=2h2j=j
V′=j=(0,1,0,0)⇒v′=(0,1,0)
아래 계산기는 같은 두 번의 곱을 임의의 축·벡터에 대해 수행합니다. 축 입력은 자동으로 단위벡터로 정규화합니다.
계산은 Hamilton 곱을 직접 두 번 적용합니다. 로드리게스 식은 별도로 계산해 결과를 대조합니다. 표의 네 성분은 모두 (x, y, z, w) 순서입니다.


06 / CONVERT & VERIFY
실제 자세를 쿼터니언으로 바꾸기
입력이 무엇인지 먼저 확인하세요. 점 하나의 위치만으로 자세는 정해지지 않습니다. RPY, 축–각, 또는 두 프레임 사이의 회전행렬이 필요합니다.
A. RPY → 쿼터니언
q = qz(ψ) ⊗ qy(θ) ⊗ qx(φ)를 전개합니다. 아래 c와 s는 반드시 각도의 절반에 대한 cos, sin입니다.
cr=cosφ2,sr=sinφ2
cp=cosθ2,sp=sinθ2
cy=cosψ2,sy=sinψ2
x=srcpcy−crspsy
y=crspcy+srcpsy
z=crcpsy−srspcy
w=crcpcy+srspsy
변환 계산기
각도를 바꾸면 쿼터니언, 회전행렬과 회전된 X 단위벡터가 함께 바뀝니다.
옅은 선: 월드 축 · 색 선: 회전 후 물체 축. 물체의 세 축은 언제나 서로 수직입니다. 축의 2D 투영은 겹쳐 보일 수 있습니다.
예시 (30°, 45°, 60°):
q ≈ (0.022260, 0.439680,
0.360423, 0.822363)


B. 좌표 프레임 → 회전행렬 → 쿼터니언
물체 프레임 B의 세 단위축을 월드 A에서 표현하여 열벡터로 쌓으면 RAB입니다. vA = RABvB. 다음은 B가 A의 Z축을 기준으로 +90° 돌아간 예입니다.
xB = (0, 1, 0), yB = (−1, 0, 0), zB = (0, 0, 1)
RAB = [ xB | yB | zB ] = ⎡0 −1 0⎤
                          ⎢1  0 0⎥
                          ⎣0  0 1⎦
trace(R) = 1
w = √(1 + trace(R))/2 = √2/2
x = (R32 − R23)/(4w) = 0
y = (R13 − R31)/(4w) = 0
z = (R21 − R12)/(4w) = √2/2
이 trace 식은 w ≈ 0인 180° 근처에 적합하지 않습니다. 일반 구현은 가장 큰 대각 성분에 따라 분기하는 알고리즘을 사용합니다. 아래 예제는 라이브러리에 맡깁니다. 입력 R은 RᵀR = I이고 det R = +1인 회전행렬인지 확인하세요. [5]
위치까지 있는 포즈라면 pA = RABpB + tAB입니다. 예를 들어 t = (1, 2, 0), pB = (1, 0, 0)이면 pA = (1, 3, 0). 회전은 q, 이동은 t에 별도로 보관합니다. 반대 프레임 변환에는 Rᵀ와 −Rᵀt를 사용합니다.


바로 재현하는 Python / ROS 2 예제
import numpy as np
from scipy.spatial.transform import Rotation as R

# 소문자 xyz = 고정축 X → Y → Z (이 자료의 RPY)
r = R.from_euler('xyz', [30, 45, 60], degrees=True)
q = r.as_quat()  # (x, y, z, w), 기본 순서
print(np.round(q, 6))
# [0.022260 0.439680 0.360423 0.822363]

R_AB = np.array([[0., -1., 0.],
                 [1.,  0., 0.],
                 [0.,  0., 1.]])
assert np.allclose(R_AB.T @ R_AB, np.eye(3))
assert np.isclose(np.linalg.det(R_AB), 1)
q_AB = R.from_matrix(R_AB).as_quat()
print(q_AB)  # [0, 0, √2/2, √2/2]
print(R.from_quat(q_AB).apply([1, 0, 0]))  # ≈ [0, 1, 0]

# ROS 2 환경에서 메시지로 전달
from geometry_msgs.msg import Quaternion
msg = Quaternion(x=float(q[0]), y=float(q[1]),
                 z=float(q[2]), w=float(q[3]))
필요 환경: Python + NumPy + SciPy. 마지막 메시지 부분은 ROS 2 환경을 source한 뒤 실행합니다. SciPy의 대문자 'ZYX' 내재 회전은 입력 순서가 [yaw, pitch, roll]이며, 소문자 'xyz'와 구별해야 합니다.
// ROS 2 / tf2: 입력 각도는 radian
#include <tf2/LinearMath/Quaternion.h>
#include <tf2_geometry_msgs/tf2_geometry_msgs.hpp>

const double d2r = 3.141592653589793 / 180.0;
tf2::Quaternion q;
q.setRPY(30*d2r, 45*d2r, 60*d2r);
q.normalize();
auto msg = tf2::toMsg(q);  // x, y, z, w
위 C++는 함수 내부에서 쓰는 핵심 코드입니다. ROS 2의 RPY·메시지 관례는 공식 튜토리얼을 따릅니다. [1]


C. 연속 회전의 갱신과 보간
월드 축 기준 회전 Δq를 추가하면 qnew = Δq ⊗ q, 물체 축 기준이면 qnew = q ⊗ Δq입니다. 매번 RPY로 바꾸고 각을 더하면 쿼터니언을 저장하더라도 특이점 문제를 다시 만들 수 있습니다.
보간 실험: 요 +170° → −170°
단순 각도 선형 보간은 340° 돌아가지만, 최단 경로 SLERP는 20° 회전합니다. 이 예시는 ±180° 경계 문제이며, 짐벌락 자체는 아닙니다. [6]
위에서 내려다본 X–Y 평면. X는 오른쪽, Y는 위쪽입니다. t = 0.5에서 왼쪽은 0°, 오른쪽은 180°입니다.
SLERP 공식과 부호 처리
q0·q1 < 0 이면 q1 ← −q1  (같은 자세, 가까운 부호 선택)
Ω = acos(clamp(q0·q1, −1, 1))
q(t) = sin((1−t)Ω)/sinΩ · q0 + sin(tΩ)/sinΩ · q1
Ω가 아주 작을 때는 정규화한 선형 보간을 사용해 0으로 나누는 문제를 피합니다. SLERP는 일정한 각속도로 두 자세 사이의 최단 회전을 따릅니다. 상대 회전이 정확히 180°면 최단 경로의 방향 선택이 유일하지 않습니다. 이 페이지의 실험도 부호 보정과 작은 각 분기를 구현합니다.


07 / PRESENT IT
35분 스터디 진행안
  1. 3분 · 용어와 약속 — 위치와 자세를 구별하고 R = Rz Ry Rx를 먼저 선언합니다.
  2. 5분 · 실험 — 일반 자세 → 피치 90° → A/B/C. “롤과 요를 같이 30° 바꾸면 왜 물체는 그대로일까요?”
  3. 5분 · 수학 — φ−ψ만 남는 행렬과 det J = cos θ를 연결합니다.
  4. 4분 · 쿼터니언 — 축–각과 반각, 길이 1 제약, q와 −q를 설명합니다.
  5. 10분 · 회전 증명 — 두 번의 곱셈 → 스칼라 소거 → 평행·수직 분해 → 숫자 예제 순으로 설명합니다.
  6. 5분 · 변환 — Z축 90° → 복합 회전 → 좌표 프레임 예시를 계산기로 확인합니다.
  7. 3분 · 정리와 질문 — 회전행렬도 해결책이라는 점, 기계 짐벌락과 각도 경계를 구별합니다.
Q. 자유도 하나가 사라지면 물체는 2차원으로 움직이나요?
아닙니다. 3D 자세 공간은 그대로입니다. 특이점에서 오일러 각 세 개의 미소 변화가 독립적인 세 회전 방향을 만들지 못한다는 뜻입니다. 기계 짐벌에서는 실제 관절이 만드는 순간 각속도 방향도 제한됩니다.
Q. 쿼터니언 4개가 서로 다른 회전 네 개를 뜻하나요?
아닙니다. 축–각 정보를 반각으로 조합한 네 성분이며 단위 길이 제약을 가집니다. x, y, z, w 각각을 독립적인 회전각처럼 해석하면 안 됩니다.
